

# Add Google and Apple Sign-In

## Overview
Add "Sign in with Google" and "Sign in with Apple" buttons to the visitor authentication page, so users can log in with one tap instead of typing email and password.

## Steps

### 1. Enable Google and Apple OAuth (automatic)
Use the Configure Social Login tool to set up both Google and Apple providers. This generates the required integration module (`src/integrations/lovable/`) and installs the `@lovable.dev/cloud-auth-js` package automatically. No API keys needed -- Lovable Cloud manages the credentials.

### 2. Update the Auth page (`src/pages/Auth.tsx`)
- Import the `lovable` client from `@/integrations/lovable/index`
- Add two social sign-in buttons above the email/password forms (visible on both Sign In and Create Account tabs):
  - "Continue with Google" (with Google icon)
  - "Continue with Apple" (with Apple icon)
- Each button calls `lovable.auth.signInWithOAuth("<provider>", { redirect_uri: window.location.origin })`
- A horizontal divider ("or") separates the social buttons from the email form

### 3. PWA compatibility
Already handled -- `vite.config.ts` already includes `/~oauth` in the `navigateFallbackDenylist`.

## Technical Details

| File | Change |
|------|--------|
| `src/integrations/lovable/*` | Auto-generated by Configure Social Login tool |
| `src/pages/Auth.tsx` | Add Google and Apple sign-in buttons with divider |

No database changes required. The existing `handle_new_user` trigger will automatically create a profile row for users who sign in via social providers.
